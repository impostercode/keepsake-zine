HEIC decoder notices

HEIC conversion uses the unmodified CSP-compatible libheif build from heic-to 1.6.6, by Hopper Gee and contributors, with libheif 1.23.6 and libde265 1.0.16. These libraries are distributed under LGPL version 3 or later, without warranty.

LGPL license · GPL/LGPL and libheif notices · Application integration source

Library source: libheif 1.23.6 · libde265 1.0.16. The unchanged generated JavaScript decoder is a separate runtime module, loaded only when needed. The worker bridge is readable JavaScript.

You may replace the decoder with an interface-compatible version and modify or reverse engineer this integration for debugging those modifications. To rebuild the app, extract the integration source, run npm ci and npm run build, then serve dist. To replace the decoder, replace dist/vendor/libheif.js after building; the worker imports that file directly. No signing or installation restriction is applied.
